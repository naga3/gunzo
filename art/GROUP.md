# gunzo の絵（全体の決まり）

gunzo は、見下ろし 2D のゼルダ風アクション。99 人の仲間を助けて、100 人で魔王を倒す。画面は 320 × 240 で、最近傍のまま拡大して見せる。

## 作風
- 人も敵も物も、**かわいいファンタジー**で統一する。2 頭身くらいで、頭が大きく、顔は下寄り。剣・杖・とんがり帽子・ローブなど、剣と魔法の世界の物で描く（現代の物、リアルな頭身、こわすぎる絵にしない）。

## 見え方
- **斜め見下ろし**（ゼルダ・神々のトライフォースのような、正面やや上から見下ろす視点）。地面は真上から、人や物は正面から見た形で描く。
- 人は **正面（`down`）だけ**。どちらへ動いても正面の絵で歩く（向きの絵は描かない。2026-10-17 に決めた。上向きは面白くなく、正面だけでゲームが成り立つ）。
- 大きさは人が 16 × 16。足もとは下の端（15 行目）にそろえる（ゲームが足もとを地面に合わせる）。

## 色
- 色は gunzo の色の表（`palette gunzo`。`art/gunzo.gpl`）だけ。.gpl は書き換えない（足りない色はユーザーに言う）。
- 光は左上から。暗い色は右と下のふちに、1〜2 点の幅で。
- 輪郭は `o`（ほぼ黒の紺）の 1 点。AA（中間色でなめらかにする）・グラデーションは使わない。

## 文字の役目（人の絵）
色はファイルの `color` の行のとおりにゲームに出る（Pixel で見えている色がそのままゲームの色）。文字は、何の部分かが分かるように、下の役目どおりに使う（色を変えたいときは、その文字の `color` の行を変える）。新しい色が要るときだけ、空いている大文字で `color` の行を足す。

| 文字 | 役目 |
|---|---|
| o | 輪郭 |
| s S | 肌、肌の影 |
| e E | 目、目の光 |
| h H j | 髪、髪の影、髪の光 |
| c C D | 服、服の影、服の光 |
| u U V | 職の服（主・影・光） |
| p P | ズボン（主・影） |
| g G l | 革（主・影・光） |
| m M n | 金属（光・中・影） |
| w | 白 |
| y Y | 金（主・光） |
| r R | 赤（主・影） |
| x X z | 職ごとの特別な色 |
